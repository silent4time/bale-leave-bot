# ربات مدیریت مرخصی بله

یک ربات کامل برای مدیریت مرخصی تیم روی پیام‌رسان **بله**  
تقویم شمسی · تایید چندمرحله‌ای · تقویم شیفتی · گزارش ماهانه

---

## این ربات چه کار می‌کند؟

با این ربات می‌توانید:

- درخواست مرخصی ثبت کنید (تک‌روزه یا چندروزه)
- مرخصی‌ها را با گردش‌کار **تایید / بررسی / رد** مدیریت کنید
- ظرفیت هر گروه را کنترل کنید تا در یک روز بیش از حد نفر مرخصی نگیرند
- تقویم را به‌صورت **روزکار** یا **شیفتی** تنظیم کنید
- گزارش ماهانهٔ خودکار دریافت کنید
- اعضا را با نقش‌های مختلف (مدیر، مسئول شیفت، ارشد، عضو) سازمان‌دهی کنید

اولین نفری که ثبت‌نام را کامل کند، **خودکار مدیر** می‌شود.

---

## پیش‌نیازها

قبل از نصب، این‌ها را آماده کنید:

| مورد | توضیح |
|------|--------|
| سرور لینوکس | Ubuntu / Debian پیشنهاد می‌شود |
| دسترسی SSH | برای ورود به سرور |
| Python 3 | اسکریپت در صورت نبود، تلاش می‌کند نصب کند |
| توکن ربات بله | از **BotFather** داخل اپ بله |

## نصب در ۳ دقیقه

### ۱) کلون کردن پروژه

```bash
sudo mkdir -p /home/bale_leave_bot
sudo chown "$USER":"$USER" /home/bale_leave_bot
git clone https://github.com/silent4time/bale-leave-bot.git /home/bale_leave_bot
cd /home/bale_leave_bot
```

### ۲) اجرای منوی مدیریت

```bash
cd /home/bale_leave_bot
bash manage.sh
```

منوی زیر ظاهر می‌شود:

```
  1) Install
  2) Update
  3) Uninstall
  4) Edit settings (token / DB path)
  0) Exit
```

### ۳) گزینهٔ ۱ را بزنید (Install)

اسکریپت به‌ترتیب:

1. پایتون را بررسی / نصب می‌کند  
2. محیط مجازی (`venv`) می‌سازد  
3. کتابخانه‌ها را نصب می‌کند  
4. **توکن ربات** را از شما می‌پرسد  
5. در صورت تمایل، سرویس ۲۴ساعته (`systemd`) می‌سازد  

بعد از اتمام، ربات آماده است.

---

## دریافت توکن ربات بله

1. اپ **بله** را باز کنید  
2. در جستجو بنویسید: `BotFather` یا `بات‌فادر`  
3. یک ربات جدید بسازید  
4. توکنی که می‌دهد را کپی کنید  
5. هنگام نصب (گزینه ۱) یا از گزینهٔ ۴، آن را وارد کنید  

---

## استفاده از منوی مدیریت

همیشه از داخل پوشهٔ پروژه:

```bash
cd /home/bale_leave_bot
bash manage.sh
```

| گزینه | کار |
|--------|-----|
| **۱ — Install** | نصب کامل + دریافت توکن + سرویس ۲۴ساعته (اختیاری) |
| **۲ — Update** | دریافت آخرین نسخه از گیت‌هاب + آپدیت وابستگی‌ها + ری‌استارت |
| **۳ — Uninstall** | توقف سرویس، بکاپ دیتابیس (اختیاری)، حذف فایل‌ها |
| **۴ — Edit settings** | تغییر توکن یا مسیر فایل دیتابیس |
| **۰ — Exit** | خروج |

## اجرای دستی (بدون systemd)

اگر سرویس ۲۴ساعته نساختید:

```bash
cd /home/bale_leave_bot
source venv/bin/activate
python3 bot.py
```

برای توقف: `Ctrl + C`

---

## دستورات مفید سرویس (اگر systemd ساختید)

```bash
# وضعیت
sudo systemctl status bale-leave-bot

# مشاهدهٔ لاگ زنده
sudo journalctl -u bale-leave-bot -f

# توقف
sudo systemctl stop bale-leave-bot

# شروع دوباره
sudo systemctl restart bale-leave-bot
```

---

## شروع کار داخل بله

1. ربات را در بله پیدا کنید و `/start` بزنید  
2. فرم ثبت‌نام را پر کنید (نام، نام خانوادگی، شماره پرسنلی)  
3. **اولین نفر = مدیر** می‌شود  
4. از منوی مدیر: گروه بسازید، ظرفیت تعیین کنید، اعضا را اضافه کنید  
5. (اختیاری) از تنظیمات، تقویم را روی حالت شیفتی بگذارید

## نکات مهم

- پیام‌های ترمینال اسکریپت **انگلیسی** هستند تا در Termux و برخی ترمینال‌ها متن فارسی خراب نشود. خود ربات داخل بله کاملاً **فارسی** است.
- زمان ثبت درخواست‌ها بر اساس ساعت **سیستم سرور** ذخیره می‌شود. منطقهٔ زمانی سرور را درست تنظیم کنید (مثلاً `Asia/Tehran`).
- توکن و دیتابیس روی سرور خودتان می‌مانند؛ به هیچ سرویس ثالثی ارسال نمی‌شوند.
- برای تست اول، با یک گروه کوچک شروع کنید.
